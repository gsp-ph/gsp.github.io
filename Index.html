Workshop participation: a Power BI report concept

An interactive browser prototype for a report that can be rebuilt in Power BI using the included fictional dataset. This is a report-design demonstration, not an embedded or completed Power BI report.

Question

How does participation vary across learning tracks and months?

Approach

Use consistent filters, count-based totals, and clearly defined rates.

Validation

Check that completed ≤ attended ≤ registered, and calculate rates from totals.

Attendance rate by month · fictional data

View fictional source data & definitions

Each row is one month and learning track. Counts represent registrations within that month; totals are not unique people across months. Attendance rate = attended ÷ registered. Completion rate = completed ÷ attended. All values are invented.
